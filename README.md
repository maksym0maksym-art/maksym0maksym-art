## 👁 Про мене

Привіт. Я **Maksm_y**, розробник низькорівневих систем та проєктів під брендом **Merden**.

Я працюю над:
- власною операційною системою **merdenOS**
- власною мовою програмування **Merden Language**
- написанням алокаторів пам'яті та системних компонентів на C
- низькорівневою розробкою під Linux / WSL / bare metal
- архітектурою систем "з нуля" — без готових фреймворків там, де це важливо

Мені подобається будувати не просто скрипти, а **фундамент**: ядро системи, мову для неї, пам'ять, якою вона керує, і інструменти навколо цього.

## 🧠 Мої проєкти

### merdenOS
Операційна система, яка розробляється з нуля під брендом Merden — ядро, системні компоненти та підтримка власної мови.

### Merden Language
Проста мова програмування, створена для модифікацій, скриптингу та зручного кодування всередині операційної системи Merden (пряма підтримка інших ОС, окрім Merden, не гарантована).

### memory-alocator
Простий алокатор пам'яті для Linux або WSL — низькорівнева робота з пам'яттю без стандартних абстракцій.

### CODE
Пісочниця для низькорівневих експериментів та напрацювань на C, які пізніше переростають у повноцінні компоненти екосистеми Merden.
